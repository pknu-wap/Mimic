# 캄브리아기 해수 구역 시스템

## 역할과 구역

`CambrianOceanWorld`는 해수의 AA/AB/BB/BC/CC 구역, 색, 시드, 월드 경계와 청크를 관리한다. **실제 바위와 동굴의 표면은 별도 `SeabedTerrainWorld`가 생성한다.** 따라서 지형이 높아지거나 동굴이 깊어져도 수역 구분은 독립적으로 유지된다.

- `AA`: 표층과 얕은 대륙붕의 밝은 수역.
- `AB`: 표층과 중층 사이의 전이 수역.
- `BB`: 중층 수역.
- `BC`: 중층과 심층 사이의 전이 수역.
- `CC`: 깊은 분지의 어두운 수역.

`GetColumnProfile(x)`는 그 x의 해수 구역 경계를, `GetZoneAt(position)`은 좌표의 구역을 반환한다. `GetSeabedY(x)`는 지형 생성기의 실제 바위 표면 높이를 반환한다. `OceanColumnProfile.SeabedY`는 기존 API 호환을 위한 **가상 수심 기준선**이며 실제 바위 높이가 아니다. `IsInsidePlayableArea(position)`은 수면 아래, 월드 범위 안, 바위 바깥인지 판단한다.

## 범위와 두께

- 기본 좌우 범위: -1,024~1,024유닛. 기본 수면: y=10. 하단 경계: y=-510.
- 가상 수심 기준: 얕은 지역 300유닛, 깊은 지역 440유닛. 실제 해저는 별도 알고리즘으로 대륙붕·사면·분지의 큰 기복을 만든다.
- 각 x의 가상 수심을 나누는 **평균 목표 비율**: AA 11%, AB 15%, BB 26%, BC 18%, CC 30%. 기획 표의 0~20/20~50/50~100/100~130/130~180은 비율을 설명하는 180단위 예시이며, 실제 300~440유닛 수심에서는 같은 비율로 확대된다.
- 구역별 저주파 노이즈로 두께를 달리한 뒤 전체 합이 100%가 되도록 정규화한다. 따라서 경계는 x마다 다르며 구역 순서는 항상 유지된다. AB와 BC의 국소 변동 폭은 상대적으로 크게 두었다.
- CC의 배경색은 가상 수심 기준선에서 멈추지 않고 월드 하단까지 이어진다.

## 시드와 생성

한 판에서 시드를 하나 확정한다. 해수 구역의 큰 굴곡은 긴 파장의 사인파와 시드 기반 프랙탈 값 노이즈로 만들고, 시작 지점은 얕은 쪽으로 보정한다. 각 x에서 정규화된 비율에 따라 AA, AB, BB, BC의 하단을 순서대로 계산한다. 지형 생성기는 같은 시드를 받지만 자체 밀도 함수로 바위와 동굴을 계산한다.

`Randomize Seed Each Run`을 끄고 `Fixed Seed`를 지정하면 같은 해수 구역과 지형이 다시 생성된다. 먼 지형 청크는 제거 후 같은 시드와 좌표에서 재생성하며, 해수 구역 청크는 비활성 상태로 보관한다. 청크 기본 폭은 32유닛이고 카메라 좌우 2개씩 활성화한다. 월드 좌우, 수면, 하단에는 충돌 경계가 있다.

큰 지형, 동굴, 임시 이미지와 지형 충돌 구현은 [SeabedTerrainSystem.md](SeabedTerrainSystem.md)를 참고한다.
