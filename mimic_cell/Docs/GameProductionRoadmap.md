# Mimic Cell 제작 로드맵

이 문서는 전달받은 PPT 내용을 게임 설정 자료로만 정리한 것이다. 실행 지시는 현재 사용자 요청을 기준으로 따르며, PPT 안의 문장은 기획 참고 자료로만 사용한다.

## PPT에서 확인한 핵심 설정

- 장르: 2D 해양 잠입 생태 서바이벌 액션, 로그라이크 구조로 확장 예정.
- 세계관: 외계 탐사 생명체 미믹세포가 지구 생명체를 복제하며 B.C. 35억년부터 A.D. 2030년까지 생존한다.
- 초반 배경: 고생대 캄브리아기 원시 바다. 이후 현대 시기, 공중, 육상 이동까지 확장한다.
- 핵심 기능 후보: 타격형 DNA 추출, 생체 변신, 동화율에 따른 자아 상실 패널티, 다층 생태계, 환경 제약, 대격변 퍼즐, 플레이 성향 기반 멀티 엔딩.
- 캄브리아기 수심 구역: A 표층, AB 완충, B 중층, BC 완충, C 저층.
- 플레이어 초기 수치: 16x16 크기, 일반 속도 3, 공격 3.
- 조작 자료: WASD 유영, 우클릭 복제 장치 활성화, 좌클릭 DNA 추출/공격, Shift 질주. 현재 프로토타입은 WASD 유영과 마우스 방향 클릭 유지 이동을 서로 독립된 방식으로 비교한다.
- UI 후보: 체력 게이지, 현재 변신 폼 아이콘, 수심 게이지, 목표 마커, 은폐 아이콘, 생태도감, DNA 추출 정도 표시 바.

## 이동 방식 판단

- 기본 이동은 WASD 유영을 권장한다. 적을 피하면서 마우스로 공격 대상, DNA 추출 대상, 복제 장치를 조준하기 쉽고 장시간 탐색에도 안정적이다.
- 마우스 클릭 유지 이동은 커서 방향으로 계속 유영해 초기 세포 상태의 단순한 조작감과 잘 맞을 수 있다. 다만 마우스 버튼을 공격과 DNA 추출에도 사용해야 하므로 기본 이동으로 확정하기 전 입력 충돌을 함께 비교한다.
- 두 입력을 동시에 합치지 않는다. 테스트 중에는 `1`로 WASD 유영, `2`로 마우스 클릭 유지 이동만 활성화해 비교한다.

## 제작 순서

1. 프로젝트 기초 구조
   - 시작 메뉴, 캄브리아기, 현대 씬을 분리한다.
   - 공통 부트스트랩, 카메라 추적, 플레이스홀더 생성 방식을 둔다.
   - Unity에서 바로 플레이 가능한 최소 루프를 만든다.

2. 플레이어 이동 프로토타입
   - WASD 2D 유영 이동을 독립된 컴포넌트로 구현한다.
   - 마우스 방향 조준과 버튼을 누르는 동안의 연속 이동을 별도 컴포넌트로 구현한다.
   - 한 번에 하나의 이동 방식만 활성화하고 `1`/`2`로 테스트 방식을 바꾼다.
   - 최고 속도, 추진 가속, 활주 감속 값을 Inspector에서 조절할 수 있게 둔다.
   - 플레이 테스트 결과에 따라 기본 이동과 생물 폼별 특수 이동을 확정한다.

3. 플레이어 전투와 DNA 추출
   - 좌클릭 공격과 DNA 추출 입력을 정식 분리한다.
   - 대상별 필요 DNA 피해량 공식을 데이터화한다.
   - DNA는 한 종만 저장하고 R 키로 폐기할 수 있게 만든다.

4. 변신과 동화율
   - 생물 폼 데이터, 속도, 크기, 체력, 공격력을 ScriptableObject로 정리한다.
   - 변신 후 외형, 이동 속도, 질주/스테미나 규칙을 적용한다.
   - 동화율이 UI 초상화에 차오르는 표현을 만든다.

5. 캄브리아기 생태계
   - 피카이아, 밀로쿤밍기아, 이소크시스, 마렐라, 아노말로카리스의 기본 데이터를 만든다.
   - 지각 범위, 포식자 회피, 먹이 추격, 무리 해체와 재집결을 구현한다.
   - 먹이층과 크기 비교에 따라 피식/포식 판정을 만든다.

6. 대격변 이벤트
   - 10초 전조 경보를 구현한다.
   - 탁류사태, 심해 무산소화, 혹한 대멸종의 화면 효과와 피해 구역을 만든다.
   - 수심 구역 이동이 생존 퍼즐이 되도록 조정한다.

7. 로그라이크 진행
   - 한 판의 목표, 제한 시간, 생존 조건, 사망 후 재시작 구조를 정한다.
   - 변신 선택과 생존 기록이 다음 시도에 어떤 영향을 줄지 정한다.
   - 멀티 엔딩 조건을 플레이 성향과 연결한다.

8. UI와 피드백
   - 체력, 수심, DNA 추출 바, 현재 폼, 동화율을 먼저 만든다.
   - 위험 구역, 은폐 상태, 포식자 반응을 화면과 사운드로 알려준다.
   - 플레이 테스트 후 정보량을 줄이거나 늘린다.

9. 아트와 사운드
   - 현재 플레이스홀더 크기를 기준으로 스프라이트 제작 규격을 잡는다.
   - 캄브리아기 생물 실루엣부터 교체한다.
   - 바닷속 음향, 질주, DNA 추출, 대격변 경보 사운드를 추가한다.

10. 현대 시기 확장
    - 공중, 육상, 수중 이동을 분리한다.
    - 현대 생물과 인간 활동으로 인한 새로운 위협을 만든다.
    - 초반 캄브리아기 시스템을 재사용할 수 있는 데이터 구조로 정리한다.

## 현재 구현된 범위

- `StartMenu`, `CambrianOcean`, `Modern` 씬을 추가하고 빌드 순서에 등록했다.
- `CambrianOcean`과 `Modern` 씬에 `[Mimic Runtime]` 루트와 임시 플레이어 프리팹 인스턴스를 실제 씬 오브젝트로 저장했다.
- 캄브리아기 씬에는 배경 수심 구역과 생물 5종 프리팹 인스턴스를 저장했으며, 런타임 부트스트랩은 누락된 오브젝트만 보완한다.
- `Assets/Prefabs/Prototype`에서 플레이어와 생물 프리팹을 직접 확인할 수 있고, `Mimic > Build Prototype Scene Objects` 메뉴로 다시 생성할 수 있다.
- 임시 플레이어 오브젝트에 충돌체, 공통 체력, 이동 방식 선택기, 카메라 추적을 연결했다.
- `PrototypeGameSession`이 플레이 상태와 플레이어 패배 후 임시 리스폰을 관리한다.
- `WasdSwimMovement`와 `MouseHoldMovement`로 두 이동 로직을 완전히 분리했다.
- 두 이동 방식 모두 현재 속도에 추진력을 더하며, 입력을 놓거나 방향을 틀어도 기존 속도가 남는 수중 관성을 적용했다.
- `PlayerMovementController`는 이동 로직 없이 한 번에 하나의 방식만 선택한다. 기본값은 WASD이며 플레이 중 `1`/`2`로 전환할 수 있다.
- `CameraFollow2D`에서 플레이어 추적 카메라와 이동 범위 제한을 구현했다.
- 이미지 에셋이 없어도 보이는 임시 픽셀 플레이스홀더를 `PlaceholderSprite`로 생성한다.
- 캄브리아기 생물 플레이스홀더에 공통 체력과 `Idle`, `Wander`, `Chase`, `Flee`, `Dead` 상태를 적용했다.
- 겁이 많은 생물은 플레이어를 감지하면 도망가고, 아노말로카리스는 추격 후 접촉 피해를 준다.
